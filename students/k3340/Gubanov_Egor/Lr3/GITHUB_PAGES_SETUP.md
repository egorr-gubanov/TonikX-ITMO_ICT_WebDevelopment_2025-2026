# Настройка GitHub Pages

## Пошаговая инструкция

### Шаг 1: Откройте настройки репозитория

1. Перейдите в ваш репозиторий на GitHub:
   ```
   https://github.com/egorr-gubanov/TonikX-ITMO_ICT_WebDevelopment_2025-2026
   ```

2. Нажмите на вкладку **Settings** (в верхнем меню репозитория)

3. В левом меню найдите и нажмите на **Pages**

### Шаг 2: Настройте источник деплоя

В разделе **"Build and deployment"**:

1. **Source**: Выберите `Deploy from a branch`
2. **Branch**: 
   - Выберите `gh-pages`
   - **Folder**: выберите `/ (root)`
3. Нажмите кнопку **Save**

### Шаг 3: Дождитесь создания ветки gh-pages

⚠️ **Важно**: Ветка `gh-pages` будет создана автоматически после первого успешного выполнения GitHub Actions workflow.

Если ветки еще нет:
1. Сначала запустите workflow (см. ниже)
2. Дождитесь его успешного завершения
3. Затем вернитесь в Settings → Pages и настройте как указано выше

### Шаг 4: Запустите GitHub Actions workflow

#### Вариант A: Автоматический запуск

Workflow должен запуститься автоматически при следующем пуше в ветку `gubanov-egorr-lr3`.

#### Вариант B: Ручной запуск

1. Перейдите в раздел **Actions** репозитория
2. В левом меню выберите **"Deploy Lr3 MkDocs Documentation"**
3. Нажмите кнопку **"Run workflow"** (справа вверху)
4. Выберите ветку: `gubanov-egorr-lr3`
5. Нажмите зеленую кнопку **"Run workflow"**

### Шаг 5: Проверьте статус деплоя

1. Вернитесь в **Actions**
2. Найдите запущенный workflow
3. Дождитесь завершения (обычно 2-3 минуты)
4. Убедитесь, что все шаги выполнены успешно (зеленые галочки)

### Шаг 6: Проверьте доступность сайта

После успешного деплоя подождите 1-2 минуты и откройте:

- **ResidentalConnect**: 
  ```
  https://egorr-gubanov.github.io/TonikX-ITMO_ICT_WebDevelopment_2025-2026/Lr3/ResidentalConnect/
  ```

- **Task1**: 
  ```
  https://egorr-gubanov.github.io/TonikX-ITMO_ICT_WebDevelopment_2025-2026/Lr3/Task1/
  ```

- **Task2**: 
  ```
  https://egorr-gubanov.github.io/TonikX-ITMO_ICT_WebDevelopment_2025-2026/Lr3/Task2/
  ```

## Частые проблемы

### Проблема: Ветка gh-pages не появляется в списке

**Решение**: 
1. Убедитесь, что GitHub Actions workflow выполнился успешно
2. Проверьте в разделе **Actions**, что деплой прошел без ошибок
3. Подождите 1-2 минуты после успешного завершения workflow

### Проблема: После настройки все еще 404

**Решение**:
1. Убедитесь, что URL заканчивается на `/`
2. Попробуйте очистить кэш браузера (Ctrl+Shift+R или Cmd+Shift+R)
3. Подождите 5-10 минут - GitHub Pages может кэшировать страницы

### Проблема: Workflow не запускается

**Решение**:
1. Проверьте, что файл `.github/workflows/lr3-docs.yml` существует в репозитории
2. Убедитесь, что вы находитесь в ветке `gubanov-egorr-lr3`
3. Запустите workflow вручную через Actions → Run workflow

## Проверка правильности настройки

После настройки в разделе **Settings → Pages** вы должны увидеть:

```
Your site is live at:
https://egorr-gubanov.github.io/TonikX-ITMO_ICT_WebDevelopment_2025-2026/
```

И зеленую галочку ✅ рядом с сообщением о том, что сайт опубликован.

## Дополнительная информация

- GitHub Pages обновляется автоматически после каждого успешного деплоя
- Изменения могут появиться не сразу (до 10 минут)
- Если что-то не работает, проверьте логи в разделе Actions
